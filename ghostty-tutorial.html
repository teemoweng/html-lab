第二章
六大核心特性
这些是 Ghostty 最值得了解的能力，每一项都直接影响你的日常使用体验。
// 01
⚡

零延迟输入

Ghostty 使用自研渲染引擎，从按键到字符出现的延迟极低（<1ms），打字如同直接刻在屏幕上。

// 02
⬜

灵活分屏

⌘D 左右分屏，⌘⇧D 上下分屏。在同一窗口里跑服务器日志的同时编写代码，告别 Alt+Tab。

// 03
🔗

超链接识别

终端里的 URL 自动变成可点击链接。⌘+Click 直接在浏览器打开，不需要复制粘贴。

// 04
📦

原生 macOS 集成

不是 Electron，是真正的原生 App。系统字体渲染、暗色模式、全屏动画全部和 macOS 无缝衔接。

// 05
🖼

图片协议支持

支持 Kitty 图片协议，可以在终端里直接渲染图片预览，配合 ranger 等文件管理器体验极佳。

// 06
⌘

完整快捷键查询

菜单栏 Help → Show Key Bindings 可以看到所有快捷键；配置文件也支持完全自定义按键映射。

第四章
配置你的 Ghostty
配置文件在 ~/.config/ghostty/config，用任何编辑器打开就能修改。下面是一份适合新手的推荐配置。
# Ghostty 新手推荐配置 # 文件路径: ~/.config/ghostty/config # 修改后重启 Ghostty 即可生效 # ── 外观 ────────────────────────────── theme = Dracula # 主题（可选: GitHub Dark, Tokyo Night, Catppuccin...） font-family = JetBrains Mono # 推荐等宽字体，支持连字 font-size = 14 # 字体大小（适合 Retina 屏） font-thicken = true # 字体加粗渲染，在 Retina 屏更清晰 # ── 窗口 ────────────────────────────── window-padding-x = 16 # 左右内边距（像素） window-padding-y = 16 # 上下内边距 macos-titlebar-style = hidden # 隐藏标题栏，更沉浸 background-opacity = 0.95 # 背景微透明（0.0~1.0） # ── 行为 ────────────────────────────── scrollback-limit = 10000 # 回滚行数（默认 3276，建议调大） copy-on-select = true # 选中即复制（像 Linux 一样） mouse-hide-while-typing = true # 打字时隐藏鼠标光标
第五章
新手必知的 5 个技巧
这些细节很多老用户也不知道，提前掌握让你少走弯路。
01

选中文字自动复制

在配置里加上 copy-on-select = true 后，鼠标选中任何文字就自动进入剪贴板，⌘V 直接粘贴，省去 ⌘C 的步骤。

02

忘了快捷键怎么办？

打开菜单栏 Help → Show Key Bindings，所有快捷键一览无余。或者去 Ghostty → Settings 直接编辑配置文件自定义按键。

03

⌘+Click 打开链接

终端输出里的 URL 会自动变成可点击的蓝色链接。按住 ⌘ 再点，就在浏览器里打开，不需要复制粘贴。

04

实时重载配置

修改 ~/.config/ghostty/config 保存后，在 Ghostty 里按 ⌘⇧, 立即重载配置，无需重启，改了主题马上看到效果。

05

拖拽文件到终端

把 Finder 里的文件直接拖进 Ghostty 窗口，文件的完整路径会自动粘贴到命令行，不用手动输入长路径。
