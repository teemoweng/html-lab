# PM 交互设计参考库 — 设计文档

> 创建于 2026-05-16

---

## 项目背景

Teemo 正在学习产品经理所需的 UI/UX 知识，核心需求是：能看到交互概念"原本长什么样"，并直接在上面进行交互，而不是看截图或动图。这个工具既是学习参考，也是日后跟设计师沟通的词汇手册。

---

## 整体定位

**名称：** PM 交互设计参考库  
**性质：** 可交互的 UI 教学演示页（Interactive Component Showcase）  
**存放位置：** `html-lab/pm-interaction-guide/`  
**文件命名：** `pm-interaction-guide.html`（v1），后续版本加 `-v2`、`-v3` 后缀

---

## 导航结构

选用**左侧固定导航栏**风格（类似 Notion / 技术文档网站）：

- 左侧深色导航栏，宽约 200px，固定不随内容滚动
- 按章节分组，每章节下展示该章所有概念条目
- 点击概念条目，右侧内容区切换至对应内容（无页面跳转）
- 导航栏顶部显示库名称和副标题

---

## 内容结构

共 6 个一级入口：

| 编号 | 名称 | 内容 |
|------|------|------|
| 导言 | 什么是交互设计 | 交互设计的几个维度、本库覆盖范围、PM 掌握这些够用在哪些场合 |
| 第一章 | 状态 (State) | Default、Hover、Active、Selected、Disabled、Loading、Error、Empty |
| 第二章 | 反馈 (Feedback) | Toast/Snackbar、Loading indicator（骨架屏/转圈/进度条）、操作确认弹窗 |
| 第三章 | 导航与布局 | Modal弹窗、Drawer抽屉、Bottom Sheet、Tab、Breadcrumb面包屑 |
| 第四章 | 交互模式 | 下拉刷新、无限滚动、拖拽排序、Accordion折叠展开、Tooltip |
| 附录 | 组件词汇表 | Chip/Tag/Badge/Button 等常见 UI 组件名词解释 |

---

## 每个概念的内容深度

每个概念页包含以下四块，固定顺序：

1. **可交互演示区** — 用户可以直接操作（hover、点击、拖拽等），感受真实效果
2. **是什么 / 为什么存在** — 概念解释，说清楚这个设计模式的存在价值
3. **PM 沟通话术** — 1-2 句示例，展示 PM 怎么跟设计师准确描述需求
4. **常见场景** — 这个概念在哪些产品场景里会遇到，用 tag 列举

---

## 技术方案

**方案：单 HTML 文件，JS 数据驱动渲染**

- 所有内容定义为 JS 数据对象，每个概念是一个对象（含名称、解释、话术、场景、演示区 HTML）
- 渲染逻辑统一，添加新概念只需在数据数组中追加一条，不改模板
- 完全自包含：CSS 和 JS 全部内联，无外部依赖，可离线打开
- 符合 html-lab 的核心约束

**文件结构：**
```
html-lab/
└── pm-interaction-guide/
    ├── pm-interaction-guide.md      ← 活文档（本设计文档将合并进去）
    └── pm-interaction-guide.html    ← v1 交付物
```

## 视觉风格

- 左侧导航：深色背景（类 Catppuccin Mocha 风格），紫色/蓝色高亮当前项
- 右侧内容区：浅色背景，高对比度
- 演示区：灰色底板，明确标注"可交互演示区"
- 三块内容卡用不同底色区分（绿色=解释、蓝色=话术、黄色=场景）
- 概念间有底部翻页按钮（← 上一个 / 下一个 →）

---

## 约束

- HTML 完全自包含，不依赖任何 CDN 或外部资源
- 演示区的交互效果用原生 CSS + 少量 JS 实现，不引入框架
- 遵循 html-lab 的版本规则：旧版保留，新版加后缀
