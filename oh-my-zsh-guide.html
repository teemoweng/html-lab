04

Git 插件缩写

Oh My Zsh 内置的 git 插件，把最常用的命令都缩短了，用几次就记住了。

缩写 完整命令 作用
gst git status 查看当前改动状态
gaa git add --all 暂存所有修改
gcmsg git commit -m 提交并写备注
gco git checkout 切换分支 / 恢复文件
gcb git checkout -b 创建并切换新分支
gp git push 推送到远程仓库
gl git pull 从远程拉取更新
glog git log --oneline --graph --decorate 可视化提交历史

在终端输入 alias | grep git 查看 git 插件全部缩写
